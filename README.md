# Little Froggy

A 3D grid-based puzzle game about a frog that is hungry to eat some flies, stay safe and go home.

This is Little Froggy's very first exciting adventure in the wilderness!!

Other working game titles:
- Froggies Feast
- The Frog Leaps


# General Game Design I'm currently thinking about:

# One of the core mechanic of the game is 'power-ups'
Just like mario and a bunch of games, there's food that you can eat that gives you some sort of ability/power-up.
These abilities will be a 1 time use. So once you use it, you return back to being a normal frogs.
These abilties cannot be stacked or added just like marios power-ups and those kinda games.

So far, we have fire ant and the flame power-up which allows frog to burn down certain objects such as bushes, or completely destroy food.

# Enemies that chases you in the map?
Frogs in the wild has predators. Maybe, there's racoons, herons or snakes or something that chases you in the map, so you need to be careful with where you go and how you solve the puzzle.
This would make sense for a slightly larger map.

# Make the game feel more like it's an open world, larger maps than 8x8
This is mainly an idea for the future. But I think it's a good diea to start implementing now.
The camera follows the frog. Each level could potentially vary in size.
Maybe, there could be the over world map and the actual puzzle maps, just like how mario and a bunch of games has the overworld map and then the gameplay inside that. Might be cool

# Map
Maybe you can press 'm' to bring up the map. The map will just have information on areas you have uncovered and all objects on the map.
It would be useful if the game is a bit more zoomed in and the map is larger, some players will want to be able to solve the puzzle by looking at the entire map on one screen.

# Should the player be forced to pickup every food or not?
Maybe there are certain food that players must pick up and certain food that the players do not need to pick up to complete the level.
This could add something to the players who are more a "completionist" type player where they might take on an extra side challenge in each puzzle map.
These could be coloured in gold or something, or just have sparkly lines emitting from the object.

# Locks that can be unlocked using a key or solving a puzzle
Something that could expand the complexity of a level.
A classic lock and key system.

# Explosive dynamites
As soon as the player pulls the block once, the dynamite will activate. After the third pull, the dynamite will explode. Something like that. The dynamite will destroy any destructible blocks in a '+' pattern.

# Multiple homes? Other characters?
Maybe there's another frog or some creature that's injured, and you've got to pull them into their home, as well as you need to get home as well.

## Narrative
This is something I would want to add at somepoint. Maybe in like comic book style or a visual novel/cut scene style. Not really sure about the style.
The story is about a little froggy's first adventure into the wild away from home. 
Something super basic that explains that this is froggy's first advanture and that froggy can't swim.
